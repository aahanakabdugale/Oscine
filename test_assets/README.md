# Test Assets

Sample evaluation assets for testing custom audio uploads in the Oscine Speech Analytics dashboard:

* **Audio:** `my_test_speech.wav` (16 kHz Linear PCM WAV)
* **Transcript:** `my_test_transcript.txt` (Plain text speech transcript)

### How to Use for Evaluation:
1. Navigate to the **"Upload Audio & Transcript"** tab on the web dashboard.
2. Select any Reference Baseline (e.g., `speech_04`).
3. Upload `test_assets/my_test_speech.wav` as the Audio file.
4. Upload `test_assets/my_test_transcript.txt` as the Transcript file (optional).
5. Click **Run Analysis** to evaluate acoustic alignment and temporal prosody anomalies.
